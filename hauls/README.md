# hauls/

Monday Haul drafts. This folder is excluded from GitHub Pages (`exclude_assets` in `.github/workflows/soft-launch.yml`) and never ships to the live site.

- `TEMPLATE.md`: the free format (approved by Cassidy, Oct 8, 2026). Copy it to `YYYY-MM-DD.md` (the Monday the issue goes out).
- `EXAMPLE-2026-10-05.md` / `.html`: the approved sample issue, week of Oct 5, 2026.
- Check and render: `npm run haul:check -- hauls/YYYY-MM-DD.md --links --html`.
- Drafts only. Nothing here is sent automatically; Cassidy sends from Buttondown (`longhaulledger`).

The routine is in RESEARCH-RUNS.md, section "Monday Haul".
